# Contributing

Issues and pull requests are welcome. For larger changes, open an issue first so
the design can be agreed before you write the code.

## Before you open a pull request

- Run `just check`; it must pass. [Develop](README.md#develop) lists the tools.
- Keep changes focused, and add or update tests for behavior you change.
- Update the README of the crate or module you touch when its behavior changes.
- Use [Conventional Commits](https://www.conventionalcommits.org/) for commit
  messages, for example `feat(tui): …` or `fix(permissions): …`.

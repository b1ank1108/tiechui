Tiechui · tc — a terminal coding agent in Rust

铁锤

终端编码代理

铁锤是用 Rust 写的终端编码代理。一个二进制，tc 与 tiechui 两个名字，提供交互式终端界面和无界面的 exec，两者共用同一套会话、模型接入、工具、权限与模块。

接入 Anthropic Messages 与 OpenAI Chat Completions 及兼容网关；会话是只追加的 JSONL，支持分支、恢复、回退与压缩；工具、命令、路径和 MCP 调用都经过规则化的权限闸门；提问、旁路对话、目标、定时提示、子代理、技能、钩子与 MCP 都以模块提供，插件可声明式打包或作为独立进程接入。
